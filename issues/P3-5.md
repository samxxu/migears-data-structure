# P3-5 — zSelect() treats every $order other than ‘ASC’ as descending, while the …

## Finding / 问题

- EN: zSelect() treats every $order other than ‘ASC’ as descending, while the interface declares only ‘ASC’|DESC’. A misspelling such as ‘ASEC’ therefore returns a silently wrong sort order instead of failing, which is the opposite of the module’s stated intent that a lowercase spelling must not fall back to DESC.
- 中文: zSelect() 把除 ‘ASC’ 以外的任何 $order 一律当作降序，而接口只声明 ‘ASC’|DESC’。‘ASEC’ 这类拼写会静默返回错误排序，而不是报错——这与模块自述的「不得静默落回 DESC」正相反。
- Where / 位置: `src/RedisDataStructure.php:315-317 (interface src/DataStructureInterface.php:90)`
- Verification / 验证: static / 仅静态推断
