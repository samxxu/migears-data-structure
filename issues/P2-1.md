# P2-1 — Roughly a dozen methods return phpredis values raw (`hashLen`, `ttl`, …

## Finding / 问题

- EN: Roughly a dozen methods return phpredis values raw (`hashLen`, `ttl`, `listLen`, `setSize`, `zSize`, `hIncrBy`, `zAdd`, `expire`, `persist` …) while their signatures promise `int`. With a stubbed connection returning false, `hashGet()` normalises cleanly to null but `hashLen()`/`ttl()`/`setSize()` throw `DataStructureException: ...Return value must be of type int, false returned` — the same failure, two different shapes, one of them a leaked PHP message.
- 中文: 约十余个方法原样返回 phpredis 的值（hashLen、ttl、listLen、setSize、zSize、hIncrBy、zAdd、expire、persist 等），而签名承诺 int。用返回 false 的桩连接实测：hashGet() 干净归一为 null，但 hashLen()/ttl()/setSize() 抛 DataStructureException: ...Return value must be of type int, false returned——同一种失败，两种形态，其中一种把 PHP 内部消息泄漏给调用方。
- Where / 位置: `src/RedisDataStructure.php:122,176,232,275,377`
- Verification / 验证: reproduced / 已实证
