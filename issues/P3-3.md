# P3-3 — `zBatchAdd()` uses the same `false` for three different meanings — …

## Finding / 问题

- EN: `zBatchAdd()` uses the same `false` for three different meanings — empty input, illegal odd length, and a failed command inside the pipeline — so callers cannot tell "nothing to do" from "bad arguments" from "partial failure".
- 中文: zBatchAdd() 用同一个 false 表示三种语义——空输入、非法的奇数长度、pipeline 中某条命令失败——调用方无法区分「无事可做」「参数错」「部分失败」。
- Where / 位置: `src/RedisDataStructure.php:325-344`
- Verification / 验证: static / 仅静态推断
