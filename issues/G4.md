# G4 — A missing logger is silent by construction: …

## Finding / 问题

- EN: A missing logger is silent by construction: `RedisDataStructure::__construct` takes `?LoggerInterface $logger = null` and then stores `$logger ?? new NullLogger()`, so the class never reports anything when no logger is supplied. `RedisLock` takes the same nullable parameter. The logger must be passed in through the constructor and required, so a call site that forgets it fails at assembly time rather than being silent at runtime.
- 中文: 缺 logger 在构造上就是静默的：`RedisDataStructure::__construct` 取 `?LoggerInterface $logger = null`，随后存下 `$logger ?? new NullLogger()`，因此没有传入 logger 时这个类什么都不上报。`RedisLock` 取同样的可空参数。logger 应当由构造函数明确传入且为必填，这样忘记传的调用点会在装配时就失败，而不是在运行时保持沉默。
- Where / 位置: `src/RedisDataStructure.php:35-37 · src/RedisLock.php:34-36`
- Verification / 验证: static / 仅静态
